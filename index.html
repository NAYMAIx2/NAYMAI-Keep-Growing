ข้อมูลบัญชีและประวัติทั้งหมดถูกเก็บรักษาไว้ในเบราว์เซอร์ของอุปกรณ์นี้อย่างปลอดภัย ไม่มีการส่งข้อมูลหรือกุญแจลับออกภายนอก

สถาปัตยกรรมสำหรับซิงก์ข้ามคอมพิวเตอร์และมือถือ:

หากต้องการให้ข้อมูลซิงก์แบบ Real-time ข้ามเครื่อง แนะนำเชื่อมต่อกับ Supabase (PostgreSQL BaaS) ซึ่งรองรับระบบ Authentication และ Row Level Security (RLS) ทำให้ผู้ใช้แต่ละคนเห็นและแก้ไขได้เฉพาะข้อมูลของตนเอง โดยใช้เพียง Public Anon Key ฝั่งหน้าเว็บ โดยไม่มีการเปิดเผย Secret Key

การตั้งค่าเชื่อมต่อ Supabase Backend (เมื่อต้องการใช้งานจริง):

*หากยังไม่ได้เชื่อมต่อระบบภายนอก สามารถใช้งานระบบจัดเก็บในเครื่อง (Local Storage) ได้อย่างสมบูรณ์แบบ และใช้ปุ่ม "สำรอง JSON" เพื่อย้ายข้อมูลข้ามเครื่องได้ทันที
